# 既存システムの隣に作るとき（brownfield）

このリポジトリの 4 パターンは新規プロジェクト向けだが、実際には「古い本体の隣に新しい機能や別クライアントを足す」仕事が多い。
そのときエージェントは、既存コードの流儀に合わせようとして **既存の壊れ方まで真似る**。
2026-11 の FMS（車両管理 SaaS）での経験から、着手前の評価手順と、新しいコードに課す規約をまとめる。

## 1. まず既存コードの保守性を測る（半日）

目的は「どこがコピーで増えているか」「唯一の定義場所がどこか」を知ること。機械的に測れるものから始める。

| 観点 | 測り方 | 旧 FMS での結果 |
|---|---|---|
| 業務ロジックのコピー | 同名関数の二重定義を grep。正規化した行の一致率をファイル対で比較 | 採点ロジック 2 系統（65% 一致）、月報 51%、Web と運営管理の認証系 40〜65% |
| レイヤ違反 | `proc.db.` / `query(` / `SELECT ` をハンドラ配下で grep | 直書き SQL 8 箇所、Redis キーの組み立て 6 箇所以上 |
| 入口の重複 | 認証・CORS・エラー応答のラッパーがいくつあるか | API 4 系統、CORS ヘッダ 4 回コピー（うち 1 箇所が構文違反） |
| 列挙値 | ロール番号・種別コードの直書き数と enum の参照数 | `case "1".."4"` が 20 箇所、enum は定義だけで参照 0 |
| 時刻変換 | `moment(`、`Date.UTC(`、`padLeft(2`、`substring(` の出現数 | サーバー 10 箇所以上、アプリ 20 箇所の手変換。同じ文字列を 2 通りに解釈 |
| 契約文書 | 文書の例と実装の応答項目を突き合わせる | 追記型で育ち、同じ節に矛盾（「写真は無し」と「写真を受け付ける」） |
| 安全網 | テスト数、lint、`strict`、CI | すべて無し。`any` 382 箇所 |

結果は `docs/` に 1 ファイル残す。「どこに何があるべきか」の判断材料になり、同じコピー分岐をしそうなときに踏みとどまれる。

## 2. 新しいコードに課す規約

新しいコードでも、半年で同じ壊れ方が始まる。CLAUDE.md に次を書く。

### 唯一の定義場所の表

「この概念の定義はここ」を名指しする表を置く。禁止だけ書くと、無いときにまた直書きされる。
**「無ければここに新設してから使う」まで書く。**

| 概念 | 唯一の定義場所（例） |
|---|---|
| API 契約 | OpenAPI。手書き文書しか無いなら「同じ PR で上書き（日付つき追記で古い記述を残さない）」 |
| 判定ルール（しきい値・超過・権限範囲） | サーバーが判定し、結果を応答に含める。クライアントは表示するだけ |
| 列挙値（種別・状態・ロール） | 1 つの enum。外部表記への変換はその enum の拡張だけ |
| 時刻変換 | 1 ファイル。項目名の接尾辞で形式を示す（`*At` = ISO 8601、`*Time` = 現地の文字列） |
| 永続化のキー・行フォーマット | 1 モジュールに組み立てと解析を置く。`split("|")[n]` を他所に書かない |
| 環境差（ローカルのスタブ） | ビルド時の差し替え。共有コードに `if (STAGE === "local")` を書かない。やむを得なければ「本番との差分」一覧に追記 |

### コピーの禁止と SYNC マーカー

- 既存コードを複製して分岐させない。共通部分を関数に切り出して両方から呼ぶ
- 既存システムの挙動に合わせる必要がある値・文言は、コピー元を `// SYNC: <リポジトリ>/<パス> <関数名>` で記す。grep で拾えるようにする
- 既存の認証・権限チェックを「ほぼ同じ」で再実装しない。差分があるなら既存側に引数を足す

### 完了条件に足すもの

機械判定（テスト・型・lint）に加えて、人が確認する項目をチェックリストで持つ。

- [ ] 契約を変えたら、同じ PR で契約文書を上書きした
- [ ] 契約を変えたら、相手側リポジトリ（サーバー ↔ クライアント）の対応を同時に作ったか、未対応を PR 本文に書いた
- [ ] 既存システムから写した値には SYNC マーカーがある
- [ ] 新しい TODO や「本番では別途対応」は引き継ぎ文書に書いた

## 3. 評価のときに使った grep（そのまま流用できる）

```bash
# ハンドラ配下の直書き SQL / Redis キー
grep -rn 'proc\.db\.\|queryRaw\|_threezero_alc' src/handler --include='*.ts'
# ロール番号・種別コードの直書き
grep -rn 'case "[1-4]"\|roleNo *== *["'"'"'][1-4]' src --include='*.ts' | wc -l
# 時刻の手変換
grep -rn 'moment\.\(utc\)\?(.*add\|Date\.UTC(\|padLeft(2\|substring(8, 10)' src lib --include='*.ts' --include='*.dart' | wc -l
# 同名関数の二重定義（export const の名前を集計）
grep -rhoE 'export const [A-Za-z_]+' src --include='*.ts' | sort | uniq -d
# 画面から API クライアント / ストアを直接触っている箇所（Flutter）
grep -rn '\.api\.\|widget\.api\|\.store\.\|\.uploader\.' lib/ui --include='*.dart'
```
